# AI Browser Agent

Автономный AI-агент для управления веб-браузером.  
Принимает текстовую задачу и выполняет её, анализируя скриншоты и взаимодействуя с интерфейсом как человек.

## Возможности
- Переход на сайты, левый и правый клик, ввод текста, скроллинг.
- Планировщик (Planner) для разбиения сложных задач на шаги.
- Универсальные правила без хардкода под конкретные сервисы.
- Persistent session для сохранения входа в аккаунты.

## Установка
```bash
pip install -r requirements.txt
playwright install chromium
```


## Настройка
Создайте файл .env с ключом Gemini API:
```bash
GEMINI_API_KEY=ваш_ключ
```

## Запуск
Предварительно запустить файл browser_session.py и зайти в свой аккаунт на сервисе, в котором агент будет выполнять задачу
```bash
python browser_session.py
------------------------------
python agent_universal.py
Введите задачу для агента: (ввести свою задачу)
```
